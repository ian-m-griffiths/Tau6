# Scalar Fundamental Measure Theory for Hard Spheres in Three Dimensions. Application to Hydrophobic Solvation
Levesque, Vuilleumier & Borgis, arXiv:1207.4950v1 (2012). First 3D implementation of the **Kierlik-Rosinberg scalar** fundamental-measure theory (KR-FMT) for hard-sphere mixtures — mathematically equivalent to Rosenfeld's vectorial FMT but with only 4 scalar weighted densities (vs 10 components) — used to add hard-sphere N-body bridge corrections to a molecular DFT of hydrophobic solvation in water.

## 3. Counter-to / reversal edges

- **C1 — "More components = more accurate" is FALSE.** The scalar KR version with 4 weights reproduces the 10-component vectorial theory *exactly* (mathematical equivalence, Phan et al. §II) — and runs ~2× faster (12 vs 24 FFTs for 2-component systems, §III). The *same* physics, a leaner register.
- **C2 — "Better equation of state = better functional" is FALSE (unresolved).** CS is more precise than PY but using it with the same weights breaks thermodynamic consistency: "there is clearly a trade off to be made between precision and theoretical consistency" (§II). Precision and consistency are *competing* gauges here.
- **C3 — "Two-body correlations are enough for water" is FALSE.** The HRF/HNC 2-body-only approximation systematically overestimates solvation free energies (16.03 vs 10.96 for methane); the hard-sphere *bridge* (order-≥3 corrections) is what restores agreement (§IV, Table I).
- **C4 — (scope reversal) "Hard-sphere corrections are universal."** They help hydrophobic/microscopic solvation but are flagged as likely insufficient for polar/charged solutes and macroscopic dewetting (§I, §V).
