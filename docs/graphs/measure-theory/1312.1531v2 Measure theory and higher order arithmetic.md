# Measure theory and higher order arithmetic
Alexander P. Kreuzer, arXiv:1312.1531v2 (2015, math.LO). A proof-theory paper: the Lebesgue measure on **all** subsets of Cantor space 2^N, formalised in the weak higher-order arithmetic `ACA0^ω + (µ)` (Feferman's µ = uniform arithmetical comprehension). Main theorem: adding the full Lebesgue measure (λ) is **Π¹₂-conservative** over the base — i.e. the measure is provably *eliminable* — with a program-extraction metatheorem.

## 3. Counter-to / reversal edges

- **C1 — "Defining the Lebesgue measure on all sets is strong/foundationally heavy" is FALSE here.** In `ACA0^ω + (µ)` the full measure on all subsets of 2^N is *consistent without an inaccessible cardinal* — Solovay's ZF model needs one, the weak theory does not (§2). The measure is cheap.
- **C2 — "A measure is indispensable content" is FALSE.** (λ) is Π¹₂-conservative: it proves *nothing new* at that level — it is a definitional/eliminable layer, not new mathematics (§2, Thm 3). Measure-as-gauge, not measure-as-content.
- **C3 — "Extensionality is needed to reason about measures" is FALSE.** The proof deliberately drops to a *neutral* non-extensional system so λ-occurrences can be substituted independently (§4.1, §4.3).
- **C4 — "You can't do analysis without the measure."** The paper's whole point: a term for the measure `λ(X)` exists in `T0` (resp. `T0[µ]`) for any *arithmetically coded* set X — the measure is computable where it matters (Lemma 7).
- **C5 — (scope) "The measure can always be replaced by integration."** Mean ergodic yes, pointwise ergodic no — exactly where the metatheorem is needed (§1, N14).

## 5. One-liner

**A formal proof that the Lebesgue measure is a conservative, eliminable, dyadic-computable add-on in a weak arithmetic — the strongest possible formal statement of Ian's thesis that the gauge (here the measure itself) is a cheap integer thing: it adds no provable content (Π¹₂-conservativity) and lives on powers of two.**
