## 3. Counter-to / reversal edges

- **The "memory" here is not stored information, it is a metastable basin:** the system doesn't *remember* the input; it stays in a stable branch of a nonlinear response because the drive history biased it there. Reversal to a naive "ternary memory cell" reading: there is no read-while-write, no refresh-free retention guarantee, and the memory *decays* (5.11 s is a relaxation time, not a retention spec).
- **Ternary OR by *power addition*, not logic:** the gate works because drive powers *add* (with a 2π/3 phase trick to make 2+2 = 2 not 4) — the "logic" is an analog magnitude comparison of a frequency shift, not a discrete gate.
- **Energy story is the reverse of ours:** their input 0 = drive OFF costs nothing *on the input side*, but the *output states* 1 and 2 are distinguished by *how much microwave power is being pumped in* — the "0" state is the absence of a signal, not an information-carrying null like our 00.
- **Hardware is room-temperature (YIG, 560 K Curie) — a genuine advantage claim** vs low-T quantum proposals, but it is *analog/microwave*, not digital silicon: no noise-margin argument, no fan-out, no composability analysis.

## 5. One-liner

**This paper gives us independent experimental proof that "0 input costs no energy" and "3 states on one physical channel" are physically real** — the tristable-cavity T-OR is exactly our `tor`/max operation realized in hardware (ANALOGY: analog magnitude vs our one-hot code), and its hysteresis-based 5.11 s memory is a cautionary counter-example to any claim that ternary memory is "free": physical multistability decays, whereas our digital fractal-RAM addressing (FR1) does not.
