## 3. Counter-to / reversal edges

- **"Ternary QFT does not behave like Hadamard"** — the standard qubit trick (phase flip = bit flip in the Hadamard basis) breaks for qutrits: QFT on {|0⟩,|1⟩,|2⟩} gives |+⟩,|−⟩,||⟩ with ω phases, and the bit-flip duality does not transfer. Correction needs pair-wise Hadamard-like H01/H12/H20 instead. Counter-to a naive lifting of the binary argument.
- **The 9-qutrit code "is similar to Shor code but its stabilizer structure is not"** — two-step error correction (detect type, then locate) is needed because the shift stabilizers detect type but not location; the apparent Shor similarity vanishes in the correction procedure.
- **Ternary here is UNBALANCED {0,1,2} mod 3** — shifts act mod 3; our balanced ternary {−1,0,+1} with carries is a different convention. Not a contradiction, but a terminological collision to resolve before mapping (see §4).

## 5. One-liner: what this paper gives us

A full error model for ternary quantum systems whose shift/phase error algebra is the same ring as ours (ω cube root = our E₁₂₀ generator, shift = Z₆ gauge rotation), whose forbidden "superposition" state is exactly our 11=NEVER trit — suggesting we treat 2'b11 as the error syndrome in RTL tests.
