## 3. Counter-to / reversal edges

- **LEAD VERDICT — this is an ANALOG synaptic/reservoir node, NOT a native multi-state storage cell, and it fails the hunt on the honest axis.** The "dual memory" is not a discrete ≥3-state cell: LTM is an *analog continuum* of partial ferroelectric polarization ("multi-level switchable polarization states" is asserted, never quantized — no level count, no discrete quantization), and STM is an *analog decaying continuum* of drain-current PPF/PPD magnitudes (µs exponential decay). There is no trit {−1, 0, +1}, no quantization, and no read of a stored discrete value. It is a fixed nonlinear dynamical map whose "memory" is a fading analog trace — exactly the reservoir-computing paradigm, which is *not* the Tau storage-cell target.
- **No storage metrics on the honest axis — this is the decisive failure.** The paper reports *task-level* numbers (NMSE, 16 reservoir states, 20 µs response, 1.5×10⁻⁷ J total task energy) and *zero* storage numbers: no bit/µm² density, no write-cycle endurance, no per-bit write/read energy, no retention time for LTM (only the qualitative "remains stable after removing the external gate voltage"). You cannot evaluate a storage cell without these; the paper never claims to be one.
- **The one energy number is worse, not better, than the comparison it cites.** Table 1 shows this work consumes 1.5×10⁻⁷ J vs Hossain et al.'s 2.72×10⁻⁸ J — i.e. ~5.5× *more* absolute energy. The abstract's "5× efficiency gain" is an energy-delay/speed construction (Hossain is 600 ms, this is 20 µs ≈ 30,000× faster), not an energy win. On the honest per-operation energy axis the FeFET is *behind*.
- **Variability is EMBRACED as a feature, the opposite of what a storage cell needs.** Device-to-device heterogeneity (gate polarization, Vgs, voltage encoding, geometry) is harvested as 16 diverse reservoir features that *lower* NMSE variance (§5, Fig.5d, Supp. Fig.6). A storage cell demands tight, repeatable distributions; this paper celebrates the spread. It is a compute/analog-design stance, not a memory stance.
- **The "multi-level" polarization collapses to ~2 qualitative behaviors, not ≥3.** The three gate set-points tested (+4 V, +3 V, −4 V) map onto only *two* outcomes: +4 V and +3 V both → PPF, −4 V → PPD. So the "multi-level" ferroelectric state reduces to a *bipolar* facilitate/depress toggle with an analog strength knob — a sign bit plus analog magnitude, not a ternary cell.
- **Metaplasticity is a weight-programming scheme, not a trit operation.** LTM's role is to *reconfigure* the STM dynamics (select PPF vs PPD, tune τ), i.e. to program a synaptic plasticity rule — an analog meta-learning mechanism. Nothing is stored as a discrete value and later read back; the "memory" is the device's dynamic trajectory.
- **There is no null state.** The "rest" state is decay-to-zero (fading memory, Supp. Note S6/S9), a *relaxation*, not a storable 00 that costs ~0 to hold. The Tau "null trit costs ~0" thesis is about a *transport encoding* (nothing on the wire); it has no counterpart in an always-conducting FET whose idle state is just the quiescent current.
- **The compute half of the thesis is untouched by the device.** All actual computation (the readout mapping) is Ridge regression in software; the device is a fixed, untrained nonlinear projection. The "2-threshold tax" on ternary compute is neither instantiated nor avoided here — the device does no threshold logic at all, and the readout pays the cost in the digital domain.

## 5. One-liner

A dual-timescale FeFET that reconfigures a volatile analog NQS dynamic (PPF/PPD) with a non-volatile analog ferroelectric polarization is an analog reservoir/synaptic node with no discrete ≥3-state storage cell and no storage-axis metrics — its only Tau touchpoint is the weak polarity≈push/pull analogy, which is bipolar, null-less, and analog, so the "0.63× native-floor flattery" trap is never even reached.
